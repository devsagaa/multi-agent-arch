Every question is one trace: a tree of timed spans (OpenTelemetry). The app writes spans and JSON logs to traces/otel/; tool calls over MCP carry the trace id in params._meta.traceparent, so the MCP server's spans and logs (a different process) land in the same trace. The numbers below are computed from those spans: per run, across runs, per operation, and by failure type.
