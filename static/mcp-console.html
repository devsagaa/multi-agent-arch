The MCP lab runs the whole flow for you. Here nothing happens unless you send it. You hold an open connection to mcp_server.py and talk to it in raw JSON-RPC. You also call the model with raw Chat Completions requests, and you carry results between the two, which is exactly the app's job. Each guided step fills in the next message from earlier responses, the way the app's code would. You can edit everything before sending, including into something invalid, to see how each side reacts.
